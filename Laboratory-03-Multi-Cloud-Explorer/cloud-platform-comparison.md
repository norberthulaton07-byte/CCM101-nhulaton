## Questions

**1. Which cloud provider offers the broadest range of services?**
AWS offers the broadest range of services because it was the first major cloud provider and has had the most time to build out its ecosystem. It provides hundreds of services covering computing, storage, databases, AI, and more. This makes it a flexible choice for almost any type of project.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure best integrates with Microsoft technologies since it was built by Microsoft itself. It connects smoothly with tools like Windows Server, Active Directory, and Microsoft 365. This makes it the natural choice for organizations already using these Microsoft products.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform is strongest in Artificial Intelligence because it created popular AI tools like TensorFlow and offers specialized hardware such as TPUs. GCP is also strong in Kubernetes since Google originally developed Kubernetes and manages it through Google Kubernetes Engine (GKE). This gives GCP an advantage for AI and container-based workloads.

**4. Which cloud platform would you personally choose and why?**
I would personally choose AWS because of its wide range of services and strong reputation for reliability. Its large global infrastructure and flexible pricing make it a good fit for both small projects and large-scale enterprise needs. It also has the largest community and documentation, making it easier to find support and solutions.
