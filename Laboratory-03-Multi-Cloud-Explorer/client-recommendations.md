# Cloud Platform Recommendations – CloudNova Technologies

## Client A – Startup Company
**Recommended Platform:** Amazon Web Services (AWS)

AWS is a strong fit for a startup with a limited budget but plans for rapid growth. It offers a generous free tier and pay-as-you-go pricing, so the client only pays for what they use as they scale. AWS also has the largest range of services in the industry, meaning the app can grow without needing to switch providers later. Its auto-scaling features let the mobile app handle sudden increases in users without manual setup.
Services they could use: **Amazon EC2** (hosting the backend), **Amazon S3** (storing app files and media), **AWS Amplify** (fast mobile app backend development).

## Client B – University
**Recommended Platform:** Microsoft Azure

Since the university already relies on Windows Server, Microsoft 365, and Active Directory, Azure is the natural choice because it integrates directly with these existing Microsoft tools. This reduces the complexity of migration and avoids retraining staff on a completely new ecosystem. Azure Active Directory allows the university to extend its current user accounts and permissions straight into the cloud. It also offers education-focused pricing and compliance support, which benefits institutions like universities.
Services they could use: **Azure Active Directory (Azure AD)**, **Azure Virtual Machines** (for hosting Windows Server workloads), **Microsoft 365 cloud integration**.

## Client C – AI Research Company
**Recommended Platform:** Google Cloud Platform (GCP)

GCP is well known for its strength in artificial intelligence, machine learning, and high-performance computing, making it the best match for a research company. It provides access to powerful hardware like TPUs (Tensor Processing Units), which are built specifically to speed up machine learning workloads. Google's own AI research (such as TensorFlow) is deeply integrated into the platform, giving developers a smoother experience. GCP also offers competitive pricing for large-scale data processing and storage needed for research datasets.
Services they could use: **Google Compute Engine** (high-performance computing), **Vertex AI** (building and training ML models), **Cloud TPU** (accelerated AI training).

## Client D – Global E-Commerce Company
**Recommended Platform:** Amazon Web Services (AWS)

AWS is ideal for a global e-commerce company because it has data centers (regions and availability zones) spread across the world, ensuring low latency for customers everywhere. Its infrastructure is built for high availability, with automatic failover so the website stays online even if part of the system fails. AWS also offers auto-scaling to handle unpredictable traffic spikes, such as during sales events, without manual intervention. Additionally, AWS has extensive experience supporting large-scale e-commerce platforms (including Amazon.com itself), making it a proven and reliable choice.
Services they could use: **Amazon EC2 with Auto Scaling** (handling traffic spikes), **Amazon CloudFront** (content delivery network for global speed), **Amazon RDS** (reliable, scalable database management).
