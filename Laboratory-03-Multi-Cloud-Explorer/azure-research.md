# Azure Research

## Brief Overview
Microsoft Azure is a cloud computing platform that provides a wide range of services, including computing, storage, networking, and databases. It is well known for its strong integration with Microsoft products like Windows Server, Active Directory, and Microsoft 365.

## Global Infrastructure
Azure's infrastructure is organized into **Regions**, each made up of one or more datacenters. Regions are grouped into **Geographies**, which help meet data residency and compliance requirements. Azure also uses **Availability Zones** within regions to protect against datacenter failures.

## Cloud Management Console
The **Azure Portal** is a web-based dashboard used to create, manage, and monitor Azure resources. It offers a customizable interface, built-in cost management tools, and integration with Azure Active Directory for access control.

## Four (4) Core Services
1. **Azure Virtual Machines** – On-demand virtual servers.
2. **Azure Blob Storage** – Scalable storage for unstructured data.
3. **Azure Active Directory (Azure AD)** – Identity and access management.
4. **Azure SQL Database** – Managed relational database service.

## Three (3) Advantages
1. Seamless integration with existing Microsoft tools like Windows Server and Microsoft 365.
2. Strong hybrid cloud capabilities for businesses combining on-premises and cloud systems.
3. Wide range of compliance certifications, useful for regulated industries.

## Typical Enterprise Use Cases
- Migrating on-premises Windows Server workloads to the cloud.
- Managing company-wide identity and access through Azure AD.
- Building hybrid cloud solutions that connect local data centers with the cloud.
