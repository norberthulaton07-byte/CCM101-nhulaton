# GCP Research

## Brief Overview
Google Cloud Platform (GCP) is a cloud computing platform offered by Google. It provides computing power, storage, and data analytics tools, and is especially known for its strengths in artificial intelligence, machine learning, and big data processing.

## Global Infrastructure
GCP's infrastructure is divided into **Regions** and **Zones**, with each region containing multiple isolated zones for reliability. GCP also benefits from Google's private global network, which connects its data centers and helps deliver fast, reliable performance worldwide.

## Cloud Management Console
The **Google Cloud Console** is a web-based interface for managing GCP resources. It provides tools for monitoring usage, managing billing, configuring security, and accessing services like AI and data analytics tools in one place.

## Four (4) Core Services
1. **Google Compute Engine** – Virtual machines for running applications.
2. **Google Cloud Storage** – Scalable object storage for data and files.
3. **Google Cloud IAM** – Identity and access management for controlling resource access.
4. **Vertex AI** – Platform for building and training machine learning models.

## Three (3) Advantages
1. Industry-leading tools for AI, machine learning, and data analytics.
2. Access to Google's fast, reliable, and secure global network.
3. Competitive pricing, especially for big data and compute-heavy workloads.

## Typical Enterprise Use Cases
- Building and training machine learning and AI models.
- Running large-scale data analytics and processing pipelines.
- Hosting applications that need Google's high-performance global network.
