# AWS Research

## Brief Overview
Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers on-demand computing power, storage, databases, and other IT resources over the internet, allowing businesses to build and run applications without owning physical servers.

## Global Infrastructure
AWS operates through a network of **Regions** and **Availability Zones** located around the world. Each Region contains multiple, physically separate Availability Zones, which helps ensure high availability and disaster recovery. AWS also uses **Edge Locations** to deliver content faster to users worldwide.

## Cloud Management Console
The **AWS Management Console** is a web-based interface that lets users manage and monitor their AWS services. It provides access to all services in one dashboard, along with billing information, security settings, and resource monitoring tools.

## Four (4) Core Services
1. **Amazon EC2** – Virtual servers for running applications.
2. **Amazon S3** – Scalable object storage for files and backups.
3. **Amazon RDS** – Managed relational database service.
4. **AWS IAM** – Identity and access management for securing resources.

## Three (3) Advantages
1. Largest and most mature cloud provider with the widest range of services.
2. Flexible pay-as-you-go pricing that suits businesses of any size.
3. Strong global infrastructure for high availability and low latency.

## Typical Enterprise Use Cases
- Hosting scalable websites and mobile app backends.
- Running big data analytics and storage solutions.
- Disaster recovery and backup for enterprise systems.
