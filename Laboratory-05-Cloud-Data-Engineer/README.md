# Laboratory 05 - Cloud Data Engineer

## Mission Overview

In this laboratory activity, I took on the role of a Cloud Data Engineer tasked with researching cloud storage solutions and deploying a working object storage server for a client. The mission involved comparing different types of cloud storage, deploying MinIO (an S3-compatible object storage server) using Docker, and interacting with it through its web console to create and manage buckets and files.

## Objectives

- Research and compare the three primary types of cloud storage: Block, File, and Object Storage.
- Deploy an object storage server (MinIO) using Docker.
- Access and navigate the MinIO web console.
- Create a storage bucket and upload a file to it.
- Document the technical deployment process and reflect on the experience.

## Tools Used

- **Docker** – used to containerize and run the MinIO object storage server.
- **MinIO (via bitnamilegacy/minio image)** – S3-compatible object storage software.
- **KillerCoda** – cloud-based Linux sandbox environment used to run Docker and access exposed ports.
- **Git & GitHub** – used for version control and submitting the laboratory activity.
- **Markdown** – used to document research and technical steps.

## Skills Learned

- Understanding the differences between Block, File, and Object Storage and when to use each.
- Deploying containerized applications using Docker, including port mapping and environment variables.
- Troubleshooting real-world deployment issues, such as discontinued Docker images and finding suitable alternatives.
- Navigating and using an object storage web console to manage buckets and files.
- Documenting technical work clearly for future reference, including deployment steps and lessons learned.
